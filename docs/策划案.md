# 嘉豪的终端 — 策划案

> **性质**：玩法基调、定位与方向（大方向，非实现细案）。  
> **实现清单**见 [产线控制脚手架.md](产线控制脚手架.md)；接口细节待 `API.md`。

---

## 1. 定位

**在 IE2 已有设备网络之上，用月之终端里的 Lua 读现场、发指令——终端是工控机，不是第二套工业包。**

---

## 2. 玩家身份

**自控工程师**：观察产线 → 写/改脚本 → 部署 → 产线按逻辑运转。

---

## 3. 核心体验

- 脚本在 **VoltNet 供电** 的月之终端上运行，输出可上 **CRT**。
- 用 **Lua + IE2 现场 API**（电路、未来的外设等）编排工厂，而不是复制 OC/CC 整机。
- **有状态写 `terminal.storage`，无状态写 `while true` + 读现场**。

---

## 4. 设计原则

- **代码控制现场，不控制菜单** — API 读写产线真实状态，不是改 UI 数字。
- **Lua 表层 / C# 底层分层** — CC 风格别名与 helper 在 `Assets/Lua/lib/`，C# Contributor 只暴露最小 `get*` 等（见 `.cursor/rules/lua-csharp-api-layers.mdc`）。
- **存档边界** — 脚本源码、启动策略、轻量 KV 进 Component；库存/流体/机器进度在世界实体里，不进 Lua VM 快照。

## 6. 待规划特性（Feature Backlog）

### 6.1 嵌套 storage（`terminal.storage` 存 table）

**状态**：未实现（0.2.0 仅标量 MVP）

**现状**

- `storage.set` / `get` 仅支持 **string、number、boolean**。
- 存档走 `ComponentMoonTerminalStorage` 的 Component 级 `ValuesDictionary`，键值扁平写入；**不支持** Lua table 一键读写。
- 临时做法：扁平键（`cfg.x`）或 Lua 侧序列化为字符串再 `set`。

**目标**

- 脚本可 `storage.set("recipe", { phase = 2, count = 10 })`，读档后 `get` 还原为 table。
- 实现路径优先 **Lua `table` ↔ 嵌套 `ValuesDictionary`**（与宿主 Save/Load 类型体系一致），避免再引入 JSON 字符串层。
- 需约定：键名冲突、嵌套深度上限、非 string 键的 table 是否允许、与扁平标量键的共存规则。

**优先级**：P1 后期或 P2（标量 storage 与产线状态机跑通后再做；不阻塞 P1 外设 MVP）。

**验收（草案）**

- 存读含 number/boolean/string 字段的 table，存档重载后字段与类型一致。
- 嵌套 table（至少一层）可 round-trip。
- 单元测试 + `Samples` 中增加最小用例。
